# 🌾 Kisan Help Desk (Kissan Help Desk)

A comprehensive web platform dedicated to empowering farmers with essential agricultural services, expert crop advisories, real-time weather forecasts, government scheme information, and an online agricultural marketplace.

---

## 🚀 Features & Modules

- **🌱 Crop Advisory**: Personalized crop recommendations, soil care tips, and localized farming guidance.
- **🧪 Fertilizer & Pesticide Guidance**: Precise dosage instructions, application timing, and safety protocols for crop management.
- **📜 Government Schemes**: Information on agricultural subsidies, welfare programs, insurance schemes, and financial aid available to farmers.
- **🌤️ Weather Forecast**: Live local weather updates, weather alerts, and seasonal advisories to plan daily farming activities effectively.
- **🛒 Farmer Marketplace**: Dedicated platform to buy and sell produce, seeds, fertilizers, and farm machinery directly.
- **💬 Query & Support System**: Interactive portal for farmers to submit farming queries and receive expert assistance.
- **🔐 User Registration & Authentication**: Secure sign-up and login workflow customized for farmers and agricultural experts.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Design & Layout**: Responsive Flexbox/Grid CSS with interactive navbar & mobile menu
- **Icons & Media**: Dynamic graphics and responsive media cards

## ⚡ How to Run Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/VeerCodex/Kisan-Help-Desk.git
   cd Kisan-Help-Desk
   ```

2. **Run via Local Server**:
   - **Option A (Python)**:
     ```bash
     python -m http.server 8000
     ```
     Open `http://localhost:8000` in your web browser.

   - **Option B (VS Code Live Server)**:
     Open the folder in Visual Studio Code and click **"Go Live"**.
